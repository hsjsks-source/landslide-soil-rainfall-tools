# 산사태 위험도 분석용 강우·토양특성 자료 수집 도구

산지 산사태 위험도 분석에 필요한 **강우**와 **토양특성** 입력자료를 공개 자료에서 수집·전처리하는 Python 스크립트입니다. 박사학위 연구(경일대학교 일반대학원 소방방재학과)의 검증 사례에 쓰기 위해 만들었습니다. 지점번호와 대상 필지 목록만 바꾸면 어느 시군에나 쓸 수 있습니다.

## 구성

| 파일 | 역할 | 사용 자료 |
|---|---|---|
| `soil_v3_collect.py` | 필지(PNU)별 토양특성 27종 조회·저장 (배수등급, 유효토심, 침식등급 등) | 농촌진흥청 국립농업과학원 「토양도 기반 토양특성 상세 정보 V3」 Open API |
| `asos_portal_process.py` | 연도별 ASOS 시간자료 병합, 결측 점검, 강우이벤트 분리, 강우 임계 판정, 선행강우(CAR) 계산 | 기상청 기상자료개방포털 지상(ASOS) 시간자료 |
| `asos_api_collect.py` | (예비) ASOS 시간자료를 Open API로 월 단위 수집 | 기상청 「지상(종관, ASOS) 시간자료 조회서비스」 Open API |

## 주요 기능

- **토양특성 수집**: PNU 목록 순차 조회, 일일 호출 한도 관리(기본 950건/일), 중단 후 이어받기, 무자료 필지 기록, 코드값 한글 해석 컬럼(배수등급·유효토심·침식등급·임지적성등급·임지저해요인)
- **강우 분석**: 무강우 24시간 기준 강우이벤트 분리, 산림청 고정기준(시우량 30mm·일강우량 150mm·연속강우량 200mm)과 Kim et al.(2020) 강우강도-지속시간 임계식 `I = 10.40·D^-0.31` 판정, 선행강우 `CAR = Σ 0.9^i · R(t-i)`(20일)
- Python 표준 라이브러리만 사용, QGIS Python Console에서도 실행 가능

## 사용법

1. `datagokr_key.example.txt`를 복사해 `datagokr_key.txt`로 바꾸고 data.go.kr 일반 인증키를 붙여넣습니다. (`.gitignore`로 커밋되지 않습니다)
2. `data/README.md`에 따라 입력자료를 준비합니다.
3. 실행

```bash
python asos_portal_process.py
python soil_v3_collect.py --pnu-file data/PNU목록.csv --prefix <시군구코드>
```

QGIS Python Console에서는 다음과 같이 실행합니다.

```python
p = r'<저장소 경로>\soil_v3_collect.py'
exec(compile(open(p, encoding='utf-8').read(), p, 'exec'), {'__name__': '__console__', '__file__': p})
```

## 산출물

- `data/토양특성V3/토양특성V3_PNU.csv` — 필지별 토양특성 (QGIS에서 연속지적도와 PNU로 조인)
- `data/ASOS_결과/` — 병합 시간자료, 일강수·CAR, 강우이벤트·임계초과표, 연도별 요약

## 유의사항

- 인증키와 원자료·결과자료는 저장소에 포함하지 않습니다. 각 원자료는 제공기관의 이용조건(출처표시 등)을 따릅니다.
- 토양특성 코드값의 의미는 국립농업과학원 OPEN API 기술명세서(토양도 기반 토양특성 상세정보 V3 ver1.0)의 코드표를 따릅니다.
