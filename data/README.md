# data 폴더

이 폴더는 공개 저장소에 포함되지 않습니다(`.gitignore`). 실행 전에 아래 구조로 자료를 직접 준비하세요.

```
data/
├─ asos_portal/       기상자료개방포털 ASOS 시간자료 (연도별 zip 또는 기간지정 csv, 파일명 무관)
├─ PNU목록.csv        토양특성 조회 대상 필지 목록 (PNU 컬럼, 19자리)
├─ ASOS_결과/         (자동 생성) 강우 분석 결과
└─ 토양특성V3/        (자동 생성) 토양특성 조회 결과
```

- ASOS 시간자료: 기상자료개방포털 > 지상(종관, ASOS) 시간자료 > 대상 지점 연도별 또는 기간지정 다운로드(같은 폴더에 섞어 넣어도 일시 기준으로 병합)
- PNU 목록: 국토교통부 연속지적도(LSMD_CONT_LDREG) 속성에서 대상 필지의 PNU를 CSV로 내보내기
